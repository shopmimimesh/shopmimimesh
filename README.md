# Mimi Mesh

### Create. Build. Explore.

Mimi Mesh is my creative workspace for turning ideas into real projects.

My work crosses different spaces, from games and interactive experiences to Web3, digital art, NFTs, community projects, and whatever idea I decide to explore next.

I’m not here because I started as a developer. I’m here because I’m a creator who wanted to understand how the things I imagine actually get built. GitHub has become part of that journey: a place to learn, collaborate with developers, organize projects, and watch ideas grow from concepts into something real.

## What I'm Building

🎮 Games & interactive experiences  
🎨 Creative & digital projects  
🌐 Web3 projects  
🖼️ Art & NFT collections  
💡 New ideas, experiments & concepts  

## The Mimi Mesh Approach

**Plan → Create → Build → Learn → Improve → Repeat**

Some projects I build myself as I learn. Others are built alongside developers and collaborators. Either way, I like being involved in the process and understanding what is happening behind the scenes.

This space will continue to grow as I do.
